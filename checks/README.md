# Checks

Every check serves the project over a local HTTP server and drives Chromium and Firefox with Playwright 1.62.1. Each exits 1 on failure.

```sh
npm install                                   # Playwright 1.62.1, from package.json
npx playwright install chromium firefox
node checks/contrast.mjs                      # [--fallback] [--browser=firefox] [--random=40] [--seed=1] [--verbose]
node checks/scoping.mjs
node checks/playground.mjs
```

- `contrast.mjs` loads the built `dials.css` and `dials-base.css`, alone, with each `themes/*.css`, and with 40 seeded sets of extreme random dials (yellows, near-white, near-black, very low chroma, saturated, with random balance, tint and white-text settings). In a light page, a dark page and an `.is-dark` band, it measures: every text token (`--text-strong`, `--text`, `--text-muted`, `--text-quiet`, `--link`) on `--surface`, `--surface-raised` and `--surface-lowered` at 4.5:1, and `--link-hover` there at 7:1 (4.5:1 in the fallback); each group's on-solid on solid at 4.5:1; its on-soft on its soft tint and on all three surfaces at 4.5:1; its line on its soft tint and the surfaces at 3:1 (not neutral's, which is the decorative `--border`); `--text` on every soft tint and on a wash between two of them (the pattern in `docs/tokens.md`) at 4.5:1; `--focus` and `--border-strong` on surface and raised at 3:1. In normal mode it also fails a coloured text or line that over-shoots: when a group's on-soft or line differs from the colour it starts from (the fill clipped to sRGB, or the dial), its worst ratio on those backgrounds must be within 0.35 of its target (the 0.1 headroom plus 0.25 for 8-bit painting). And it checks the field numbers from two real sites: `#007a70` on white keeps its colour, `#d04a04` lands between 4.5 and 4.85:1 with its hue, and teal text on a navy `.is-dark` band lands between 4.5 and 5.3:1. It also fails any of those foregrounds that is translucent, and checks that on-solid text is opaque on a translucent fill. With `--fallback` it measures the same pairings on the fallback for older browsers, emulated as below, in a light page and an `.is-dark` band (the fallback has no dark page), and reports the random dial sets' pass rate.
- `exceptions.json` lists failures the contrast check tolerates, each with a reason. Normal mode has none, and no theme ever gets one. The fallback has one per colour group, for random dial sets only: its on-solid text is a fixed white or black, which extreme fills can defeat.
- `scoping.mjs` checks that `[data-dials]` re-derives colour and space, that a site setting the deprecated `--accent` (at `:root` or in a scope) still gets its secondary colour, with `--accent-*` and `.is-accent` following, `--grey` changes paper and ink, an exact `--paper-light` wins, base rules lose to a later zero-specificity rule even on `:hover` and `:focus-visible`, that the fallback (emulated) follows a site's purple brand, exact paper and `--accent`, re-derives a `[data-dials]` scope, keeps `.is-danger` winning and darkens an `.is-dark` band, and that the last resort (emulated) is valid and flat.
- `playground.mjs` loads `site/` and checks there are no console errors, and that every preset, theme, Randomise, the scheme switch, the format switch and both export modes work.
- `lib.mjs` holds the shared server and browser launcher, and `emulateFallback`, which emulates an older browser on the text of `dials.css`: it turns the fallback's `@supports` on and breaks relative colour, `light-dark()` and gradient interpolation (and `color-mix()`, for the last resort) everywhere else, so anything that relies on them fails as it would there. Both checks print what it patched. If Playwright's own Firefox build isn't installed, it uses `DIALS_FIREFOX` or another Firefox build in the Playwright cache.
